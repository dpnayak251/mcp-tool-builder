Privacy Policy

Last Updated: October 3, 2026

1. Our Core Privacy Philosophy

MCP Tool Schema Builder was created for developers and AI engineers who value security and data confidentiality. The application operates entirely inside your local web browser (client-side execution). We do not transmit, collect, process, or store your schema definitions, API parameters, or code outputs on any remote server.

2. What Data Leaves Your Machine?

None. All schema generation, validation, TypeScript/Zod compilation, Python syntax formatting, and JSON-RPC serialization happen locally within your device's browser memory using JavaScript.

3. Cookies and Tracking

This website does not use tracking cookies, third-party analytics trackers (like Google Analytics), or behavioral advertising fingerprinting. When you use the "Share Link" feature, the tool data is encoded directly into the URL hash fragment (`#state=...`) which is never sent to the web server during HTTP requests.

4. Hosting & Server Logs

Static assets (HTML, CSS, JS, SVG) are served over HTTPS via secure web servers (such as Hostinger / Cloudflare CDN). Standard server access logs (IP address, browser user-agent) may be temporarily recorded by the hosting infrastructure solely for DDoS mitigation and uptime verification.

5. Open Source & Transparency

Because all source code runs in the browser, you can inspect the entire application logic at any time via your browser's Developer Tools (Ctrl+Shift+I or Cmd+Option+I) under the Sources tab.
