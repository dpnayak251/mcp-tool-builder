FastMCP: Build Python Model Context Protocol Tools in 10 Lines

Published October 3, 2026 • 6 min read • Python Tutorial

While the official MCP Python SDK requires significant boilerplate to register JSON schemas and manage event loops, FastMCP provides a high-level, FastAPI-like developer experience for building MCP tools with Python type hints.

1. Installing FastMCP

pip install "mcp[cli]"

2. The 10-Line FastMCP Server

Create server.py:

from mcp.server.fastmcp import FastMCP

mcp = FastMCP("MathSuite")

@mcp.tool()
def calculate_compound_interest(principal: float, rate: float, years: int) -> float:
    """
    Calculates the final balance with compound interest.

    Args:
        principal: Starting balance in USD.
        rate: Annual interest rate percentage (e.g. 5.5 for 5.5%).
        years: Number of years to compound.
    """
    return round(principal * ((1 + (rate / 100)) ** years), 2)

if __name__ == "__main__":
    mcp.run()

3. Automatic Schema Extraction

Notice how FastMCP inspects Python type hints (principal: float) and docstrings (Args:) to automatically generate the standard MCP JSON Schema without writing any JSON by hand.
